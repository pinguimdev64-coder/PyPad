# PyPad ~ BlocoDeNotas-CLI Feito em Python ~



## Como **usar**?

- Para sair aperte `CTRL+d`

- Para personalizar, abra o `config.json` você verá "text_status", "text_editor" e a cor global (o theme) "global_color"
> O "*text_status*" é da status bar, e o "*text_editor*" serve para mudar a cor do texto no editor e a "*global_color*" mudar todo o tema, o padrão é *RedHack/RedHacker* mas pode mudar para seu gosto ;)

## Sobre

#### Esse projeto ainda não salva ou abre aquivos, ele ainda é *v1.1.2*, no futuro, posso adicionar uma função de abrir arquivos, a versão v1.1.1 contem bugs e é instável e não dar para personalizar.
